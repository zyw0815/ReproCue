# Contributing

1. Open an issue with the problem, intended behavior, and a way to verify the change.
2. Update `develop` and create a development or fix branch from it.
3. Open a pull request against `develop`. Link the issue and record the checks you ran.
4. Merge verified work into `develop`, then delete the temporary branch. Keep `develop` as the long-lived integration branch.
5. Keep `main` runnable. Merge `develop` into `main` for a release or tag.

If a bug fix still needs confirmation, keep the issue, pull request, and branch open until the reporter verifies the fix.
